How to Use

  1. Enter the name of your SQL table.
  2. Paste your CSV data into the input box.
  3. Make sure the first row contains the column names.
  4. Click Convert to SQL.
  5. Copy the generated SQL or download it as a `.sql` file.

The converter generates SQL INSERT statements from your CSV data. Numeric values, boolean values and empty values are handled automatically.

FAQ

What does this CSV to SQL converter generate?
It generates SQL INSERT INTO statements using the first CSV row as column names.

Can I choose the SQL table name?
Yes. Enter your desired table name in the SQL Table Name field before converting the CSV.

Are my CSV data uploaded to a server?
No. The conversion is performed directly in your browser.

What happens to empty CSV values?
Empty values are converted to SQL NULL.

Can I download the generated SQL?
Yes. Use the Download SQL button to save the generated statements as a `.sql` file.
