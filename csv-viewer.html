CSV table preview

What the CSV Viewer shows

The first row becomes the table header, and each following CSV record appears as a row. The viewer reads comma-delimited text decoded as UTF-8. It is useful for checking a spreadsheet export, inspecting column names, or finding a value before converting the data.

How to view a CSV file

  1. Paste comma-separated text or choose a .csv file.
  2. Select View CSV to parse the header and display the table.
  3. Use the row filter to find matching values. It searches across all parsed records.
  4. Scroll within the table to inspect wide columns or additional rows.

CSV example

name,city,note
Ada Lovelace,London,"Research & analysis"
Grace Hopper,"New York","Said ""debug the system"""

The viewer displays text as text, so values that resemble HTML are not executed as page markup. If a file has more than 500 matching records, the first 500 matches are shown; refine the filter to narrow the preview.

Common troubleshooting

  • Columns do not line up: fields containing commas must be enclosed in double quotes.
  • Quotation marks appear in a value: represent a quotation mark inside a quoted CSV field as two double quotes.
  • The input is tab-separated: use TSV to JSON or CSV to TSV for tab-separated data.
  • Semicolons are used as separators: the viewer expects commas and does not infer locale-specific delimiters; normalize the file to comma-separated UTF-8 text first.
  • No rows appear: the first row is reserved for headings; add a header row and at least one non-empty record.

CSV stays in your browser

When you select a file, this page reads it with the browser File API and creates the preview in JavaScript. CSV contents are not sent to a conversion server. CSV Viewer FAQs

Can I preview a CSV file as a table?

Yes. Paste CSV text or choose a .csv file to display its header row and records in a scrollable table.

Does the CSV Viewer support quoted commas and line breaks?

Yes. It handles commas and line breaks inside double-quoted fields, as well as doubled double quotes inside a quoted value.

Are my CSV contents uploaded to a server?

No. The browser reads the selected file and creates the table locally; the viewer does not send CSV contents to a conversion server. The website separately loads analytics scripts; see the Privacy Policy for site-wide practices.

Can I search the CSV rows?

Yes. The row filter searches the parsed cell values without changing the input file. Up to 500 matching rows are displayed at a time to keep the page responsive.

Does the CSV Viewer edit or save my original file?

No. The viewer previews the CSV data and offers a filter; it does not modify or save over the original file.
