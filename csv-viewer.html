CSV table preview

What the CSV Viewer shows

The first row becomes the table header, and each following CSV record appears as a row. The viewer reads comma-delimited text decoded as UTF-8. It is useful for checking a spreadsheet export, inspecting column names, or finding a value before converting the data.

How to open a CSV file online

  1. Paste comma-separated text or choose a .csv file.
  2. Select View CSV to parse the header and display the table.
  3. Use the row filter to find matching values. It searches across all parsed records.
  4. Use Previous page and Next page to move through the preview, then scroll horizontally for wide columns.

CSV example

name,city,note
Ada Lovelace,London,"Research & analysis"
Grace Hopper,"New York","Said ""debug the system"""

The viewer displays text as text, so values that resemble HTML are not executed as page markup. If a file has more than 500 matching records, the first 500 matches are shown; refine the filter to narrow the preview.

Common troubleshooting

  • Columns do not line up: fields containing commas must be enclosed in double quotes.
  • Quotation marks appear in a value: represent a quotation mark inside a quoted CSV field as two double quotes.
  • The input is tab-separated: use TSV to JSON or CSV to TSV for tab-separated data.
  • Semicolons are used as separators: the viewer expects commas and does not infer locale-specific delimiters; normalize the file to comma-separated UTF-8 text first.
  • No rows appear: the first row is reserved for headings; add a header row and at least one non-empty record.

Open a CSV file online to inspect its rows

An online CSV table viewer is useful when you want to check a spreadsheet export before importing or converting it. Instead of reading a wall of commas, view CSV files in a browser as labeled columns and records. This is handy for checking headings, locating a value, or confirming that quoted commas stayed inside the right cell.

The first non-empty record supplies the column headings, and cell values remain text rather than being converted into dates or numbers. Search across the parsed rows, then navigate the preview in pages of 50. To keep the page responsive, at most 500 matching rows are displayed at a time; refine the search to inspect a later match. This viewer expects comma-separated UTF-8 input and does not sort, edit, or save the original file.

After reviewing a CSV file, continue with CSV to JSON for an array of records or CSV to XML for flat XML rows. If your source is an Excel workbook, use Excel to JSON.

CSV stays in your browser

CSV Viewer FAQs

How do I open a CSV file online?

Paste CSV text or select a .csv file, then choose View CSV. The page uses the first non-empty row as column headings and displays the parsed records in a searchable table in your browser.

Does the CSV Viewer support quoted commas and line breaks?

Yes. It handles commas and line breaks inside double-quoted fields, as well as doubled double quotes inside a quoted value.

Are my CSV contents uploaded to a server?

No. The browser reads the selected file and creates the table locally; the viewer does not send CSV contents to a conversion server. Its preview is marked for Microsoft Clarity masking, while other page-level analytics may still collect usage events; see the Privacy Policy for details.

Can I search the CSV rows?

Yes. The row filter searches all parsed cell values without changing the input file. The preview shows up to 500 matches in pages of 50 rows; refine the filter to find matching rows beyond that preview limit.

Does the CSV Viewer edit or save my original file?

No. The viewer previews the CSV data and offers a filter; it does not modify or save over the original file.
