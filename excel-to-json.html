What this Excel to JSON converter does

This browser-based tool reads a selected worksheet and turns its header row and records into a JSON array of objects. It supports common Excel workbook files ending in .xlsx and .xls. Workbooks with multiple sheets can be converted one worksheet at a time.

How to convert Excel to JSON

  1. Choose an .xlsx or .xls workbook from your device.
  2. After the workbook loads, select the worksheet you want to convert.
  3. Select Convert worksheet to JSON to create an array of records.
  4. Review the result, then copy it or download converted-data.json.

Example structure

If the worksheet starts with the headings name, department, and active, each subsequent row becomes an object:

[
  {
    "name": "Ada Lovelace",
    "department": "Research",
    "active": true
  },
  {
    "name": "Grace Hopper",
    "department": "Engineering",
    "active": false
  }
]

Headers, values, and limitations

  • The first non-empty row supplies object keys. Use clear, unique headings for predictable JSON properties.
  • Numbers and Boolean values remain numbers and Booleans; recognized date cells are written as ISO date strings. Empty worksheet cells become empty strings.
  • Formula cells are not recalculated. If the workbook contains a cached formula result, that stored result is read.
  • This tool does not refresh external workbook connections, execute macros, preserve cell formatting, or convert multiple worksheets into one combined array.
  • Only .xlsx and .xls are offered as supported inputs here. Password-protected files that the parser cannot decrypt will fail to open.

Common troubleshooting

  • No worksheet appears: confirm the file opens in a spreadsheet application and contains at least one visible sheet.
  • Properties are unexpected: make sure the first non-empty row contains the intended unique column names.
  • Formula output is blank or old: the workbook may not contain a saved formula result; recalculate and save it in a spreadsheet application, then select the file again.
  • The page feels slow: larger workbooks need more browser memory and processing time. Try a smaller workbook or one worksheet at a time.

Convert an Excel spreadsheet to a JSON array

A worksheet is a useful starting point when an API, web application, or test fixture expects records as JSON objects. This Excel to JSON converter uses the first non-empty worksheet row as property names and turns each later row into an object in an array. Clear, unique headings make the resulting JSON easier to use in code.

To convert XLSX to JSON or convert XLS to JSON, choose the workbook, select the worksheet, and review the output before copying or downloading it. Each worksheet is converted separately. The tool reads stored formula results when available; it does not recalculate formulas, refresh external connections, or preserve spreadsheet formatting. If you need to clean or validate the resulting JSON, continue with the JSON Formatter; for comma-separated source data, use CSV to JSON.

Excel to JSON FAQs

Which Excel file types are supported?

This page accepts .xlsx and .xls workbooks. Macro-enabled .xlsm and binary .xlsb files are not listed as supported input formats.

Can I choose a worksheet from a workbook?

Yes. After the workbook is read locally, choose one of its worksheet names from the selector. The first worksheet is selected initially.

How are spreadsheet values represented in JSON?

The first non-empty worksheet row supplies object keys. Numeric and Boolean cells remain typed values, blank cells become empty strings, and recognized date cells are serialized as ISO date strings.

Does this converter recalculate spreadsheet formulas?

No. It reads formula results stored in the workbook when available; it does not run Excel's calculation engine or refresh external data connections.

Are my Excel files uploaded?

No. The workbook is read and parsed by JavaScript in this browser using a locally hosted library. The conversion page does not send workbook contents to a conversion server. Its panel is marked for Microsoft Clarity masking, while other page-level analytics may still collect usage events; see the Privacy Policy for details.
