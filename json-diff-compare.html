How to Use JSON Diff & Compare

  1. Paste the first JSON object into JSON A.
  2. Paste the second JSON object into JSON B.
  3. Click Compare JSON.
  4. Review the added, removed, and changed values.
  5. Use Copy Result to copy the comparison.

Frequently Asked Questions

What does this JSON comparison tool do?

It compares two JSON objects and identifies values that were added, removed, or changed between them.

Does this tool upload my JSON data?

No. The comparison is performed locally in your browser and the JSON data is not uploaded to a server by this tool.

Can I compare nested JSON objects?

Yes. The tool can compare nested JSON objects and reports differences using their property paths.

Can this tool compare JSON arrays?

The current version is designed to compare JSON objects rather than top-level JSON arrays.
