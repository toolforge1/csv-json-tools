FAQ

What is JSONL?

JSONL, also called JSON Lines, stores one valid JSON object per line. It is useful for processing records individually.

What is NDJSON?

NDJSON means Newline Delimited JSON. It is a line-based format in which each line contains a separate JSON value, commonly a JSON object.

What JSON format does this tool accept?

This converter expects a JSON array containing JSON objects.

Can I convert an empty JSON array?

No. An empty array does not contain any records, so the tool displays an error message instead.

Is my JSON data uploaded?

No. The conversion is performed directly in your browser and your JSON data is not uploaded to our server.
