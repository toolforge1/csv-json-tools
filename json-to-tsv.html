JSON to TSV Guide

How to Convert JSON to TSV

This JSON to TSV converter turns a JSON array containing objects into tab-separated values. Each object property becomes a TSV column, while each JSON object becomes a row in the generated output.

  1. Paste a valid JSON array containing objects into the input box.
  2. Click Convert to TSV.
  3. Review the generated tab-separated data.
  4. Copy the TSV result or download it as a .tsv file.

Example JSON Input

[
  {
    "name": "Ali",
    "age": 28,
    "city": "Karachi"
  },
  {
    "name": "Emma",
    "age": 34,
    "city": "London"
  }
]

Example TSV Output

name	age	city
Ali	28	Karachi
Emma	34	London

The converter automatically collects property names from the JSON objects and uses them as TSV headers. If a later object contains a property that was not present earlier, that property is also added as a column.

About TSV

What Is TSV?

TSV stands for Tab-Separated Values. It is a plain-text data format where columns are separated by tab characters instead of commas. TSV files are commonly used for spreadsheets, data exports, databases, scripts and data-processing workflows.

Because TSV is plain text, it is easy to generate, read and process with many programming languages and spreadsheet applications.

JSON vs TSV

JSON is structured and well suited for APIs, applications and nested data. TSV is more table-oriented and is useful when the data needs to be represented as rows and columns.

Converting JSON to TSV can therefore be useful when structured JSON data needs to be opened or processed as tabular data.

Developer Notes

JSON to TSV Conversion Details

Input format

The converter expects the top-level JSON value to be an array. Every item in the array must be an object.

Different object properties

Objects do not need to contain exactly the same properties. The converter builds a combined list of property names and creates columns for them. Missing properties produce empty TSV cells.

Nested values

If a property contains an object or another array, that value is converted to a JSON string before being placed into the TSV cell.

Tabs and line breaks

Tab characters and line breaks inside individual values are replaced with spaces so they do not interfere with the TSV row and column structure.

FAQ

Frequently Asked Questions

What JSON format does this tool support?

The input should be a JSON array containing objects. The properties of those objects are converted into TSV columns.

What happens if objects have different properties?

The converter combines the property names from all objects into the TSV header. A missing property results in an empty cell for that object.

Are nested JSON objects supported?

Nested objects and arrays can be included as values. They are converted into JSON text inside the corresponding TSV cell.

Is my JSON uploaded to a server?

No. The conversion runs directly in your browser. The JSON input is not sent to our server by this tool.

Can I download the TSV file?

Yes. After conversion, use the Download TSV button to save the generated data as converted.tsv.

Can I copy the TSV result?

Yes. Click Copy TSV to copy the generated tab-separated data to your clipboard.

JSON to TSV: input rules, output behavior, and troubleshooting

Paste a non-empty JSON array; every item must be an object. Keys form a first-seen union of columns, missing or null values become empty cells, and nested values become JSON text in a cell.

What the converter produces

Tabs and CR/LF characters inside values are replaced with spaces. The output always has a header row and literal tabs; this page does not accept top-level objects, scalar arrays, URL input, or file upload.

Example / practical check: Example: objects {"name":"Ali","city":"Karachi"} and {"name":"Sam","age":30} produce a union header with city and age columns; each absent value is an empty cell.

Common problems and how to fix them

Check valid JSON, a non-empty array of objects, and inspect the header and row count before copying or downloading. Use JSON to CSV for comma-delimited output or JSON to JSONL for one record per line.
