What Is URL Decoding?

URL encoding, also known as percent encoding, represents certain characters using a percent sign followed by hexadecimal values. This is commonly used when data needs to be safely represented inside URLs.

URL decoding reverses this representation. For example, encoded spaces, punctuation and Unicode characters can be restored to their original text.

How JSON URL Decoding Works

This tool uses the browser's built-in decodeURIComponent() function to decode the input. The resulting text is then passed to JSON.parse().

If both steps succeed, the JSON is formatted with two-space indentation and displayed in the output editor.

URL Encoded JSON 
%7B%22name%22%3A%22Ali%22%2C%22age%22%3A28%7D
Decoded JSON 
{
  "name": "Ali",
  "age": 28
}

Unicode and Urdu Support

URL encoding can represent Unicode characters as percent-encoded sequences. Because the decoder uses the browser's Unicode-aware URL decoding function, encoded text can include Urdu and other non-Latin scripts.

Developer note: This tool expects the decoded result to be valid JSON. It is intended for URL-encoded JSON data rather than arbitrary URL query strings or complete web URLs.
FAQ

Frequently Asked Questions

Does this tool validate the decoded JSON?

Yes. After URL decoding, the resulting text is parsed with JSON.parse(). If it is not valid JSON, an error is displayed.

Does it support Urdu and other Unicode characters?

Yes. URL-encoded Unicode characters can be decoded and displayed as readable text, including Urdu and other non-Latin scripts.

Is my data uploaded to a server?

No. The decoding and JSON processing happen directly in your browser. Your input is not uploaded to our server by this tool.

Can I download the decoded JSON?

Yes. After decoding, click Download JSON to save the formatted result as a JSON file.

Can I copy the decoded JSON?

Yes. Click Copy JSON after a successful decoding operation.

What happens if the URL encoded text is invalid?

The browser's URL decoding operation can return an error for malformed percent-encoded sequences. The tool displays the resulting error message.
